# US Open and Australian Open

Two datasets.

## Match index

`data/matches.csv` lists every men's and women's quarterfinal, semifinal, and final at the Australian Open and the US Open from 2000 through 2026. Scores come from the Jeff Sackmann tennis data archive (CC BY-NC-SA 4.0).

## Match Charting Project

`data/match-charting/` is the Australian Open and US Open rows from [Jeff Sackmann's Match Charting Project](https://github.com/JeffSackmann/tennis_MatchChartingProject). That extract includes every round and year in the project, not only the quarterfinals in the index. File names match the upstream repository. Point files are still split by decade.
